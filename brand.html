An identity built on one idea: a B held inside a D. The B is the work — structure, components, decisions — and the D contains it. Everything in the system comes from a single radius, halved and halved again, so the same logic that draws the logo also sets the type scale, the spacing and the icons.

01 · The monogram
R = 48
The D's outer radius. Cap height is 2R = 96; the mark is 88 × 96.
R/2 = 24
Each of the B's two bowls, stacked to the same 96.
Weight 15
Stem, both bars and the D's wall — one weight, no optical tapering.
Six paths
No strokes, no boolean ops. Rebuilds in Figma from circles and rectangles.

03 · Usage rules
Do
Keep clear space of one stem width (15 units) on all four sides.
Use the periwinkle counter on light backgrounds; use #A9B2D8 on dark.
Below 20px use the one-colour version — the counter fill is dropped.
Place the mark on flat colour or a quiet area of an image, always full-bleed-free.
Don't
Don't outline, add shadow, gradient or emboss the mark.
Don't recolour the B — the letterform stays charcoal or reversed white.
Don't stretch, rotate, or shear; don't rebuild it with a typeface B and D.
Don't set the wordmark in Semibold or tighten the tracking below +0.12em.
Clear space is measured from the mark's bounding box, not from the curve. One stem width is enough — the mark is compact and does not need a large exclusion zone, which matters on a resume header where vertical space is scarce.

Rules of thumb: text is never a pastel; one pastel dominates per surface; #4B57A8 is the only colour allowed on a button or link. Pastels lighten as they recede — periwinkle for brand moments, mist blue for structure, lavender for large quiet fields.
05 · Typography
Display 300
48–64 / 1.1 / -0.02em
Heading with emphasis
28–36 / 1.15 / 300 + 600
Body copy is Montserrat Regular at 16px with 1.75 line-height and a 65-character measure. Montserrat is wide, so the measure matters more than the size: keep paragraphs narrow and they read comfortably.
16 / 1.75 / 65ch
Label 600 uppercase
11–12 / 0.2em
One family. Montserrat 300 / 400 / 500 / 600 only. The 300-against-600 contrast does all the emphasis work — no italics, no third weight in a heading.
Tracking. Negative (-0.02em) above 28px, zero for body, positive (+0.2em) for uppercase labels. Never track lowercase text.
Optional third role. IBM Plex Mono 400 for specs, versions and metadata only — captions and figures, never body or headings.
06 · Spacing & motifs
8 / 16 / 24 / 40 / 64 / 96. A doubling-and-a-half scale, same halving logic as the mark. Section padding 96, block gaps 40, element gaps 16. Nothing in between.
Two motifs. Concentric radii as a section device, and the repeated bowl as a rhythm across banners and covers. Both are the logo's geometry at 4px stroke — never mistaken for the logo itself.
Icons. 24-unit box, 1.6px stroke, round caps and joins, 4–5px corner radii — the same softness as the mark's curves. Outline only; never filled, never two-tone.
